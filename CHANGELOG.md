# Changelog

Version history for the Olibana Project Root Specification. This spec is a living document; each substantive revision increments the version and is recorded here.

## v1.1 — 2026-08-15

Website programme, Phase 0–1. No implementation code.

- `docs/website/01_SITE_AUDIT.md` — Phase 0 audit across all 20 required sections. Findings: greenfield repository, no Fashion Specification anywhere in the account, empty Atlas data logs, no tech stack, no commerce infrastructure, no assets.
- `docs/website/02_BRAND_EXPERIENCE_SYSTEM.md` — translation thesis, six principles as enforceable rules, three-layer world, signature interactions, silence budget, prohibition checklist.
- `docs/website/03_INFORMATION_ARCHITECTURE.md` — full target IA with per-route blockers, MVP-0 build set, navigation model, URL conventions, search schema.
- `docs/website/04_MOTION_LANGUAGE.md` — five motion tokens with durations, easings, and cited Atlas sources; prohibitions; reduced-motion mapping; browser-support strategy.
- `docs/website/05_VISUAL_SYSTEM.md` — token architecture with brand colour values deferred per the measurement-first decision; construction palette; light-state architecture; colour derivation protocol.
- `Character_Bible.md` → v1.1. Additive extension only; sections 1–3 unchanged. Adds photography direction, web voice, motion character, and an explicit list of facts required from the owner.

## v1.0 — 2026-08-15

Initial specification.

- `README.md` — project vision, core philosophy, six design principles, Atlas index, repository map.
- `Brand_Bible.md` — mission, core values, brand promise, identity keywords.
- `Character_Bible.md` — persona, voice-in-practice table, visual expression.
- `River_Atlas.md` — flow, curvature, reflection; measurement templates and design translation.
- `Stone_Atlas.md` — fracture, strata, edge geometry; surface grammar.
- `Forest_Atlas.md` — branching, bark, canopy; hierarchical proportion.
- `Light_Atlas.md` — time of day, season, shadow, atmosphere; color and material rules.
- `Design_System.md` — unified design language, evaluation criteria, validation checklist, metrics, iteration process.

Atlas data logs are present but empty, pending field measurement.
