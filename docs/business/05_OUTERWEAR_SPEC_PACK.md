# OUTERWEAR SPEC PACK — 견적 발송용

**Version:** v1.0 · **Date:** 2026-08-15
**Category:** Outerwear ([ADR-005](../adr/ADR-005-garment-category.md))
**Purpose:** 공급자가 공수를 계산할 수 있는 최소 정보를 완성한다.
**Fill rule:** 모르는 항목은 `미정`으로 남긴다. **추정값을 쓰지 않는다** — 잘못된 사양은 잘못된 견적을 만들고, 그 견적으로 가격을 정하면 손실이 확정된다.

> **미학 방향은 이 문서의 대상이 아니다.** 공장은 스타일이 아니라 **공수**를 견적한다. 아래 항목은 전부 공수를 결정하는 구성 요소다. ([ADR-006](../adr/ADR-006-brand-direction-conflict.md) 참조 — 미해소 상태이나 이 단계를 막지 않는다.)

---

# A. 품목 확정

```
□ 코트 (기장 무릎 이상)      □ 하프코트          □ 블루종 / 봄버
□ 트렌치                     □ 테일러드 재킷      □ 필드 재킷
□ 기타: ____________
```

**선택 1개.** 공수 차이가 가장 큰 단일 항목이다.

# B. 실측 시트

**측정 방법:** 옷을 평평한 바닥에 펴고, 단추/지퍼를 잠근 뒤, **한쪽만** 재고 표기한다(가슴너비 = 겨드랑이 아래 1cm 지점의 좌우 폭, 반쪽 수치). 단위 **cm**, 소수점 1자리.

| # | 측정 항목 | 측정 위치 | S | M | L |
|---|---|---|---|---|---|
| 1 | **총장** | 뒷목중심(BNP) → 밑단 | | | |
| 2 | **어깨너비** | 좌 어깨끝 → 우 어깨끝 | | | |
| 3 | **가슴너비** | 암홀 아래 1cm, 반폭 | | | |
| 4 | **허리너비** | 가장 좁은 지점, 반폭 (없으면 `-`) | | | |
| 5 | **밑단너비** | 밑단 끝, 반폭 | | | |
| 6 | **소매길이** | 어깨끝 → 소매끝 | | | |
| 7 | **소매통** | 암홀 아래 1cm, 반폭 | | | |
| 8 | **소매부리** | 소매 끝단 반폭 | | | |
| 9 | **암홀깊이** | 어깨끝 → 겨드랑이 직선 | | | |
| 10 | **앞기장** | 앞목중심(FNP) → 밑단 | | | |
| 11 | **목너비** | 좌 목점 → 우 목점 | | | |
| 12 | **라펠/칼라 폭** | 가장 넓은 지점 (없으면 `-`) | | | |
| 13 | **여밈 겹침분** | 앞단 겹치는 폭 | | | |

**3사이즈 전부 필요하다.** 그레이딩 편차(사이즈 간 증감치)를 공장이 알아야 패턴 비용을 산출할 수 있다.

> **가장 빠른 방법:** 소장한 아우터 중 실루엣이 가장 가까운 것 1벌을 M으로 잡아 실측하고, S/L은 원하는 증감을 적는다. 처음부터 3벌을 실측할 필요는 없다.

**측정 기준 의류:** `____________________` (브랜드/품목 — 공장 전달용 참고 정보)

# C. 구성 사양 — 공수 결정 항목

각 항목이 공수를 얼마나 움직이는지 표기했다. `공수↑↑↑`는 단가에 큰 영향을 준다.

## C-1. 겉감
```
소재 방향:  □ 울   □ 코튼   □ 린넨   □ 나일론/테크니컬   □ 혼방   □ 미정
중량:      □ 경량   □ 중량   □ 중량 이상   □ 미정
조달:      □ 공장 수배 요청   □ 자체 지급   □ 미정
```
> **원단 최소 구매 단위를 반드시 물어야 한다.** 아우터는 벌당 원단 소요가 커서, 봉제 MOQ가 아니라 **원단 MOQ가 실질 최소 수량을 결정할 가능성이 높다.**

## C-2. 안감 — `공수↑↑↑`
```
□ 전체 안감   □ 반안감   □ 안감 없음(시접 처리 필요)   □ 미정
```

## C-3. 심지 / 접착 — `공수↑↑`
```
범위: □ 앞판 전체   □ 칼라·라펠만   □ 부분   □ 없음   □ 미정
```

## C-4. 여밈 — `공수↑↑`
```
방식: □ 단추   □ 지퍼   □ 스냅   □ 지퍼+단추   □ 미정
개수: ______ 개
히든 플래킷:  □ 유   □ 무
```

## C-5. 칼라 / 라펠 — `공수↑↑↑`
```
□ 노치드 라펠   □ 피크드 라펠   □ 스탠드 칼라   □ 후드
□ 칼라 없음     □ 기타: __________   □ 미정
```

## C-6. 포켓 — `공수↑↑`
```
유형: □ 웰트   □ 플랩   □ 패치   □ 사이드심   □ 없음   □ 미정
개수: 외부 ______ 개 / 내부 ______ 개
```

## C-7. 소매 — `공수↑↑`
```
부착: □ 셋인   □ 래글런   □ 드롭숄더   □ 미정
소매부리: □ 플레인   □ 커프스   □ 조절 탭/스트랩   □ 시보리
```

## C-8. 벤트 / 밑단
```
벤트: □ 센터   □ 사이드   □ 없음
밑단: □ 접어박기   □ 바인딩   □ 드로스트링   □ 미정
```

## C-9. 이음선 구성 — `공수↑↑↑` · **브랜드 규칙이 실행되는 지점**
```
앞판 분할:  □ 없음   □ 프린세스   □ 각진 패널 분할   □ 미정
뒤판 분할:  □ 없음   □ 센터심   □ 요크   □ 각진 패널 분할   □ 미정
패널 총 개수(추정): ______
```
> 이 항목이 Stone Atlas의 파단각 규칙이 물리적으로 실행되는 유일한 자리다. **동시에 공수를 가장 크게 움직이는 항목이기도 하다.** 패널이 늘면 단가가 오른다. 규칙과 원가가 만나는 지점이므로, 견적을 **분할 있음/없음 두 가지로 요청**하면 그 비용을 정확히 알 수 있다.

## C-10. 스티치 / 마감
```
탑스티치: □ 있음(위치: __________)   □ 없음
특수 마감: □ 파이핑   □ 바인딩   □ 본봉만   □ 미정
```

## C-11. 부자재
```
단추/지퍼 지정: □ 공장 제안   □ 자체 지정   □ 미정
기타 하드웨어: __________
```

## C-12. 라벨 — **법정 표시 의무**
```
□ 품질표시(조성·취급) 공장 제작 요청
□ 브랜드 네임 (제작: □ 공장 □ 자체)
□ 행택 (제작: □ 공장 □ 자체)
□ 미정
```
> 조성·취급 표시는 판매 시장 대부분에서 **법적 의무**다. 누가 작성·부착하고 문구 책임은 누구에게 있는지 견적 단계에서 확정한다.

## C-13. 포장
```
□ 개별 폴리백   □ 박스   □ 지정 없음(공장 표준)   □ 미정
```

# D. 참고 이미지

```
□ 실루엣 참고 1~2장     전체 형태·기장·볼륨
□ 디테일 참고 1~2장     칼라·포켓·여밈·이음선
□ 원단 참고 1장         질감·중량·광택
```

**출처를 반드시 표기한다.** 공장에는 "이 정도 수준" 전달용이며, **타 브랜드 디자인을 복제 지시로 사용하지 않는다** — 원본 제작 의뢰임을 명시한다.

# E. 발송 팩 조립 체크리스트

```
□ 1. A 품목 확정
□ 2. B 실측 시트 (3사이즈)
□ 3. C 구성 사양 (미정 항목은 미정으로 표기)
□ 4. D 참고 이미지
□ 5. 도식화 (앞·뒤) — 손그림 가능. C 항목이 채워져 있으면 정밀도는 낮아도 된다
□ 6. 02_FIRST_GARMENT_EXECUTION.md §1.2(日本語) 또는 §1.3(한국어) 질문지
□ 7. 추가 질문: 「MOQ 미만 생산 시 조건」 (03_SUPPLIER_SOURCING.md)
□ 8. 추가 질문: 「C-9 패널 분할 유/무 2가지 견적」
```

**발송처:** `03_SUPPLIER_SOURCING.md` §1 — 후보 3~5곳, 서울패션허브 포함 권장.
**발송 원칙:** 전 후보에 **동일 문구·동일 수량 구간(10/20/30/50/100)**. 문구가 다르면 비교가 성립하지 않는다.

# F. 회신 이후 — 사용자 결정 불필요

```
견적 회신
   ↓ 원문 그대로 보존 (SupplierQuote, append-only)
   ↓ UNIT_ECONOMICS_CALCULATOR.xlsx 입력
   ↓ 손익분기 수량 산출
   ↓ 판매가 결정
   ↓ PreorderRun.minimum_quantity 확정
```

이 구간은 계산이므로 자동 진행된다. 다음 사용자 결정은 **판매가 승인** 시점에 발생한다.
