## ⚠️ 먼저 — Part 1의 가정을 수정한다

`02_FIRST_GARMENT_EXECUTION.md`에서 최소 구성을 **10~50장**으로 상정했다. 조사 결과 **이 가정이 낙관적일 가능성이 높다.**

확인된 범위:

| 경로 | 공개된 최소 수량 |
| --- | --- |
| RAKUMADE (JP) | 50장~ |
| makemade (KR) | 100장~ (소량생산 기준) |
| 일부 OEM 제휴 공장 | 1형 100착~ |
| 개인 대응 서비스 (JP) | 1착~ (단, 단가 매우 높음) |

**즉 "소량"이라는 말이 업계에서 뜻하는 수량은 50~100장이지, 10~30장이 아니다.**

이것이 왜 중요한가:

```
pre-order 최소 수량 = 손익분기 수량
                    = MOQ 이상이어야 성립

MOQ가 100장이면 → pre-order 100장을 모아야 생산 착수
                → 신생 브랜드 첫 상품으로는 매우 높은 허들
```

**따라서 견적 요청 시 반드시 확인해야 할 항목이 하나 더 생긴다:**

> **「MOQ 미만으로 생산할 경우의 조건」** — 단가 할증을 감수하고 20~30장 생산이 가능한지, 가능하다면 그때의 단가는 얼마인지.

이 답이 「불가」로 돌아오면 선택지는 셋뿐이다.

1. **MOQ까지 pre-order를 모은다** — 기간을 길게, 목표를 명확히
2. **1착 대응 서비스로 시작한다** — 단가는 높지만 MOQ가 없다. 첫 한 벌 완주에는 오히려 적합할 수 있다
3. **품목을 바꾼다** — 액세서리·소품은 봉제 의류보다 MOQ가 낮은 경우가 많다

**이 판단은 견적 회신 후에 한다.** 지금 결정하지 않는다.

## 2. 발송 전 정리해야 할 것

**질문지를 보내기 전에 이것이 없으면 견적이 오지 않거나, 와도 비교 불가능한 형태로 온다.**

| 항목 | 필요 수준 | 현재 |
| --- | --- | --- |
| 품목 확정 | 코트/재킷/셔츠/니트 중 하나 | ❌ 미정 |
| 디자인 도식화 | 앞·뒤 라인 드로잉 | ❌ 없음 |
| 사이즈 스펙 | 3사이즈 주요 치수 | ❌ 없음 |
| 원단 방향 | 소재·중량·질감 | ❌ 없음 |
| 참고 이미지 | 유사 실루엣·디테일 | ❌ 없음 |

**최소한 품목과 도식화는 있어야 한다.** 「코트를 만들고 싶다」만으로는 견적이 나오지 않는다. 공장은 봉제 공수를 계산해야 하고, 공수는 디테일 수에서 나온다.

**지금 준비 가능한 최소 패키지:**

```
1. 품목 1개 확정
2. 앞·뒤 도식화 (손그림도 가능. 정확도보다 디테일 개수가 중요)
3. 주요 치수 3사이즈 (기존 소장 의류를 실측해서 기준 삼는 방법이 가장 빠르다)
4. 참고 이미지 2~3장 (실루엣 / 디테일 / 원단 각각)
5. 02번 문서 Part 1 질문지
```

3번은 Atlas 실측과 별개다. **이건 옷의 치수이지 자연의 치수가 아니다.** 브랜드 규칙 도출은 나중이고, 지금은 공장에 전달할 사이즈 기준이 필요할 뿐이다.

## 3. 발송 절차

```
STEP 1  후보 3~5곳 선정
        · 일본 2곳 + 한국 2곳 이상 (시장 비교)
        · 공공 기관 1곳 반드시 포함

STEP 2  동일한 질문지를 동일하게 발송
        · 문구를 바꾸지 않는다 → 비교 불가능해진다
        · 수량 구간(10/20/30/50/100)을 반드시 동일하게

STEP 3  회신 도착 → 원문 그대로 보관
        · SupplierQuote는 append-only
        · 요약하지 말고 원문 저장

STEP 4  비교 → 손익분기 수량 계산
        · UNIT_ECONOMICS_CALCULATOR 사용

STEP 5  샘플 제작 1곳 결정
        · 최저가가 아니라 소통 품질로 고른다 (§4 참조)
```

**3~5곳인 이유:** 1곳이면 비교 기준이 없고, 10곳이면 회신 관리가 무너진다. 그리고 §58 금지 10에 따라 **단일 공급자 의존은 그 자체가 리스크(R-13)**이므로, 최소 2곳은 실제 대화까지 진행한다.

## 4. 판단 기준 — 최저가로 고르지 않는다

| 신호 | 의미 |
| --- | --- |
| ✅ 질문에 **항목별로** 답한다 | 견적서를 읽는 상대다 |
| ✅ MOQ·리드타임을 **숫자로** 말한다 | 실제 캐파를 안다 |
| ✅ 원단 MOQ를 먼저 언급한다 | 실무를 안다 |
| ✅ 불가능한 것을 불가능하다고 한다 | **가장 중요한 신호** |
| ⚠️ "뭐든 됩니다" | 공수 계산을 안 했다 |
| ⚠️ 수량 구간별 단가를 못 준다 | 원가 구조가 없거나 중개만 한다 |
| ⚠️ 샘플 없이 양산 가능하다 | 품질 리스크 |
| 🛑 계약·권리 질문(15번)을 회피 | 디자인 보호 불가 |
| 🛑 선금 100% 요구 | 신생 브랜드에게 매우 불리 |

**첫 거래에서 가장 비싼 것은 단가가 아니라 소통 비용이다.** 리드타임을 지키지 않거나 질문에 답하지 않는 공장은, 단가가 20% 싸도 pre-order 납기 약속을 무너뜨린다. 그리고 납기 약속 파기는 R-10 — 브랜드 신뢰의 문제로 번진다.

---

## 5. 이 단계에서 하지 않는 것

```
✗ 계약 체결          — 샘플 전에 계약하지 않는다
✗ 선금 지급          — 샘플비 외
✗ 원단 대량 구매     — 견적 전
✗ 공급자 1곳 확정    — 최소 2곳 유지 (R-13)
✗ 공장 실명을 확정된 파트너처럼 문서화  — 대화 전까지는 후보일 뿐
```

## 6. 다음 행동

```
1. 품목 1개 확정                          ← 오직 이것만 결정하면 된다
2. 도식화 + 치수 + 참고 이미지 준비
3. 후보 3~5곳 선정 (서울패션허브 포함)
4. Part 1 질문지 + 「MOQ 미만 생산 조건」 추가하여 발송
5. 회신 → 계산기에 입력 → 손익분기 수량 확정
```

**1번이 유일한 결정이고, 나머지는 작업이다.** 품목이 정해지지 않으면 나머지 전부가 멈춘다.
