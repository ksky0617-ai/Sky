**Version:** v1.0 · **Date:** 2026-08-15

**Scope:** 카테고리 선택 자체는 하지 않는다 (G-05). 선택 이후 필요한 모든 것을 미리 확정한다.

## 0. 이 문서가 하는 일과 하지 않는 일

| 한다 | 하지 않는다 |
| --- | --- |
| 각 카테고리가 **어떤 브랜드 규칙을 물리적으로 실행할 수 있는지** 판정 | 어느 카테고리가 더 아름다운지 판단 |
| 구조적 복잡도의 **상대 순서** 도출 | 원가·MOQ·리드타임의 **절대 수치** 제시 |
| 카테고리별 견적용 실측 항목 확정 | 카테고리 선택 |
| 도식화 체크리스트 확정 | 디자인 |

**절대 수치는 전부 `UNKNOWN`이다.** 견적 회신 전에는 알 수 없고, 지어내지 않는다.

## 1. 브랜드 규칙 실행 가능성 — 취향이 아니라 구조 판정

LOCKED 문서(`Design_System.md`, 4개 Atlas)에 기록된 설계 규칙이 각 카테고리에서 **물리적으로 실행 가능한가**를 판정한다. 이것은 미학 판단이 아니라 구성 사실이다 — 니트에는 패널 이음선이 없으므로 파단각 이음선을 넣을 수 없다는 것은 취향의 문제가 아니다.

| Atlas 규칙 | 실행 형태 | (a) 아우터 | (b) 니트 | (c) 셔츠/컷소 | (d) 액세서리 |
| --- | --- | :---: | :---: | :---: | :---: |
| **Stone** — 파단각 | 각진 패널 이음선 | ✅ 완전 | ❌ 불가 | ⚠️ 제한적 | ⚠️ 품목별 |
| **Stone** — 층리 중첩 | 레이어드 헴·단 | ✅ | ⚠️ | ⚠️ | ⚠️ |
| **Stone** — 카빙된 엣지 | 파이핑·트림 라인 | ✅ | ❌ | ✅ | ✅ |
| **River** — 사행 곡률 | 헴라인 곡선 | ✅ 완전 | ⚠️ | ✅ | ⚠️ |
| **River** — 유선 간격 | 플리츠·주름 간격 | ✅ | ❌ | ⚠️ | ❌ |
| **River** — 드레이프 거동 | 원단 낙하 | ✅ | ✅ | ⚠️ | ❌ |
| **Forest** — 분기 비율 | 어깨:밑단 비례 위계 | ✅ | ✅ | ✅ | ⚠️ |
| **Forest** — 반복 모티프 | 니트 조직·자수 | ⚠️ | ✅ 완전 | ⚠️ | ⚠️ |
| **Forest** — 질감 대비 | 매끈/거친 병치 | ✅ | ✅ | ⚠️ | ✅ |
| **Light** — 반사율 | 소재 광택 선택 | ✅ | ✅ | ✅ | ✅ |
| | **실행 가능 규칙 수** | **9–10** | **5–6** | **6–7** | **4–5** |

### 판정

- **(a) 아우터** — 문서화된 규칙 거의 전부를 실행할 수 있는 유일한 카테고리다. 패널 구성·엣지·곡률·드레이프가 모두 살아 있다.
- **(b) 니트** — Forest 계열(반복·질감·비례)은 강하나, **Stone 계열이 구조적으로 불가능**하다. 니트는 재단·봉제 구조가 아니다.
- **(c) 셔츠/컷소** — 엣지와 곡률은 가능하나 패널 언어가 얇다.
- **(d) 액세서리** — 엣지·질감·소재는 가능하나 실루엣 규칙(곡률·비례·드레이프)이 대부분 적용되지 않는다.

> **이것은 (a)를 고르라는 뜻이 아니다.** 규칙 실행 가능성은 결정의 한 축일 뿐이고, 자본 위험·MOQ·리드타임이라는 반대 축이 있다. 두 축은 서로 역방향이다 — 규칙을 가장 잘 담는 카테고리가 가장 비싸고 느리다.

## 2. 구조적 복잡도 — 상대 순서만

절대 수치는 견적으로만 알 수 있다. 그러나 **상대 순서는 구성에서 도출된다**(패턴 피스 수와 봉제 공정 수는 구조적 사실이다).

| 축 | 상대 순서 (낮음 → 높음) |
| --- | --- |
| 패턴 피스 수 | 액세서리 < 니트 < 셔츠 < 아우터 |
| 봉제 공정 수 | 액세서리 < 니트 < 셔츠 < 아우터 |
| 부자재 종류 | 니트 < 액세서리 < 셔츠 < 아우터 |
| 원단 소요량 | 액세서리 < 셔츠 < 니트 < 아우터 |
| 샘플 반복 예상 횟수 | 액세서리 < 셔츠 < 니트 < 아우터 |
| **→ 단가** | 액세서리 < 셔츠 < 니트 < 아우터 |
| **→ 리드타임** | 액세서리 < 셔츠 < 니트 < 아우터 |
| **→ pre-order 손익분기 수량** | **UNKNOWN — 견적 필요** |

| 항목 | 값 |
| --- | --- |
| 생산원가 (절대) | `UNKNOWN` |
| MOQ (절대) | `UNKNOWN` — 조사된 업계 관행은 50~100장대이나 공급자별 상이 (`03_SUPPLIER_SOURCING.md`) |
| 리드타임 (절대) | `UNKNOWN` |
| 원단 최소 구매 단위 | `UNKNOWN` — **봉제 MOQ보다 이것이 실질 제약일 가능성** |

**핵심 긴장:** §1의 규칙 실행 가능성과 §2의 자본 위험이 **정확히 역순**이다. 이 트레이드오프가 HG-2026-001의 실체다.

## 3. 카테고리별 견적용 실측 항목

공급자가 공수를 계산하려면 치수가 필요하다. 아래는 **표준 실측 항목**이며, 소장 의류를 평평하게 놓고 재면 된다(브랜드 규칙 도출과 무관한 순수 작업).

### (a) 아우터 — 코트/재킷
```
총장(뒷목중심→밑단) · 어깨너비 · 가슴너비(암홀 아래 1cm)
소매길이(어깨끝→소매끝) · 소매통 · 소매부리 · 암홀깊이
밑단너비 · 앞기장 · 라펠폭(있을 경우) · 여밈 겹침분
```
### (b) 니트
```
총장 · 어깨너비 · 가슴너비 · 소매길이 · 소매통 · 소매부리
목너비 · 목깊이 · 밑단너비 · 밑단 시보리 높이 · 게이지(있을 경우)
```
### (c) 셔츠 / 컷소
```
총장 · 어깨너비 · 가슴너비 · 소매길이 · 소매통 · 커프스 둘레
목둘레 · 요크 너비 · 밑단너비 · 앞단 너비
```
### (d) 액세서리
```
품목별 상이 — 최대 외곽 치수(가로×세로×폭) · 스트랩 길이·폭
개구부 치수 · 하드웨어 규격 · 총중량
```

**3사이즈(S/M/L) 전부 필요하다.** 그레이딩 편차를 공급자가 알아야 한다.

## 4. 도식화 체크리스트 — 정확도보다 디테일 개수

공수는 **디테일 수**에서 나온다. 손그림도 무방하나, 아래 항목의 유무는 명시되어야 한다.

**전 카테고리 공통 (앞·뒤 2장)**
```
□ 실루엣 외곽선          □ 모든 이음선 위치
□ 여밈 방식과 개수        □ 포켓 유무·위치·유형
□ 스티치 위치            □ 밑단 처리 방식
□ 목선 형태              □ 소매 부착 방식
```
**아우터 추가:** 안감 유무 · 라펠/칼라 형태 · 벤트 · 견장/탭 · 조절 스트랩 · 심지 범위
**니트 추가:** 조직 패턴 · 시보리 위치 · 넥라인 마감 · 이음 방식(링킹/오버로크)
**셔츠 추가:** 칼라 유형 · 커프스 유형 · 요크 · 플래킷 · 다트/턱
**액세서리 추가:** 하드웨어 종류·수량 · 스트랩 구조 · 내부 구획 · 마감 처리

## 5. 결정 후 즉시 실행 가능한 순서

카테고리 한 단어가 정해지면 아래가 순차 실행된다. **1~3은 사용자 작업, 4~5는 자동.**

```
1. §3의 해당 실측 항목으로 3사이즈 치수 기록      (소장 의류 실측)
2. §4의 해당 체크리스트로 앞·뒤 도식화             (손그림 가능)
3. 참고 이미지 2~3장 (실루엣 / 디테일 / 원단)
4. 위 3개 + 02번 문서 §1.2/§1.3 질문지 → 발송 팩 조립
5. 03번 문서의 후보 3~5곳에 동일 발송
```

**4번 이후로는 사용자 결정이 더 필요하지 않다.** 견적이 돌아오면 계산기에 입력 → 손익분기 수량 → 판매가 순으로 자동 진행된다.

## 6. 결정에 여전히 필요한 것 — 최소화된 범위

```
DECISION ID:      HG-2026-001
남은 결정:         카테고리 한 단어
                  (a) 아우터  (b) 니트  (c) 셔츠/컷소  (d) 액세서리

이 문서로 확정된 것:
  ✅ 각 카테고리의 브랜드 규칙 실행 가능성 (구조 판정)
  ✅ 상대적 복잡도·단가·리드타임 순서
  ✅ 카테고리별 실측 항목
  ✅ 카테고리별 도식화 체크리스트
  ✅ 결정 후 실행 순서

여전히 UNKNOWN:
  ⬜ 절대 원가·MOQ·리드타임      → 견적으로만 해소
  ⬜ 손익분기 수량               → 견적 이후 계산

권고:              없음 (G-05 — 승인되지 않은 미학적 가치 판단 금지)
```

**결정의 실체는 하나의 트레이드오프다:** 브랜드 규칙을 가장 온전히 담는 카테고리가 자본 위험과 리드타임도 가장 크다. 어느 쪽에 무게를 둘지는 브랜드 소유자의 판단이다.
